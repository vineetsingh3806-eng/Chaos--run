# CHAOS RUN — 2D Android Adventure Platformer

**CHAOS RUN** is an original retro pixel-art 2D adventure platformer for Android where the environment itself is the player's primary obstacle. Designed and engineered for commercial publication on the Google Play Store, CHAOS RUN features **50 fully playable levels across 5 distinct worlds (10 levels per world)**, an intelligent environmental chaos engine, true contact-triggered instant disappearing floors, real-time procedural Indian chiptune instrumental music, checkpoint environment restoration, and a privacy-first, offline architecture.

---

## Game Highlights

- **The Environment is the Enemy**: Zero monsters, zero zombies, zero combat. Every challenge is created by intelligent reactive terrain: instant disappearing floors, crumbling timber bridges, rolling boulders, hidden floor spikes, shifting stone pillars, and rising magma surges.
- **Original Protagonist ("Aarav the Seeker")**: An independently designed adventurer sporting a saffron travel turban with brass-rimmed goggles, an earthy teal utility vest, and a dynamically waving ochre scarf with physics-based wind motion.
- **True Instant Disappearing Floors**:
  - On player contact, the floor immediately sets both visibility (`isVisible = false`) and collision solidity (`isSolid = false`) in the **exact same game update frame**.
  - If the player is standing on it, gravity pulls the player downward immediately without ground support.
  - Supports both surprise floors (zero warning) and short-warning floors (0.25s - 0.35s trembling warning before collapsing).
  - Normal crumbling platforms are preserved separately (~0.8s crumble with dust debris).
- **Snapshot Checkpoint System**:
  - Touching a checkpoint captures an exact snapshot of Aarav's position, dynamic tile states (collapsed/disappeared floors), moving hazard positions/trajectories, and lava heights.
  - Upon death, the world environment and Aarav are restored precisely to the checkpoint snapshot. Permanent unlocked levels and settings in SharedPreferences are never lost.
- **Procedural Indian Instrumental Audio**:
  - Pure mathematical wave synthesis using native Android `AudioTrack` without random noise or static loops.
  - 1990s-inspired Indian classical ragas (Bilawal, Khamaj, Bhupali, Yaman/Bhairavi, Bhairav) with bansuri/flute, sitar-like plucks, warm keyboard/string pads, resonant tabla (bayan/dayan) percussion, and smooth crossfades between worlds.
  - Zero external commercial samples or copyright liabilities.
- **50 Playable Levels Across 5 Worlds (10 Levels per World)**:
  1. *World 1: Green Forest* (Levels 1 – 10: Whispering Woods, Banyan Hollow, Canopy Crossing, Bramble Maze, Mossy Cascades, Monsoon Run, Whispering Ravine, Ancient Timberline, Shifting Grove, Guardian Banyan)
  2. *World 2: Dark Jungle* (Levels 11 – 20: Twilight Vines, Ancient Temple Ruins, Bioluminescent Cavern, Forgotten Sunken Altar, Canopy Abyss, Mantis Ridge, Emerald Hollow, Serpent Step, Viper Chasm, The Temple of Shadows)
  3. *World 3: Lava Valley* (Levels 21 – 30: Magma Caldera, Obsidian Crags, Inferno Ascent, Brimstone Ridge, Basalt Step, Cinder Cavern, Molten Conduit, Furnace Falls, Ashfall Chasm, Heart of the Volcano)
  4. *World 4: Frozen Mountain* (Levels 31 – 40: Frostbite Ridge, Glacier Chasm, Crystal Summit, Blizzard Pass, Avalanche Hollow, Shattered Icefield, Howling Peak, Glacial Serenade, Permafrost Rift, Pinnacle of the North)
  5. *World 5: Haunted Castle* (Levels 41 – 50: Dungeon Bastion, Mechanism Crypt, The Chaos Throne, Obsidian Keep, Phantom Gallery, Gothic Spire, Vault of Whispers, Catacomb of Echoes, Iron Portcullis, Sanctum of the Chaos Master)
- **Local Progress & Stats**: Collectible coins, speedrun timer, 3-star ranking system, and audio settings saved locally on your device.
- **100% Offline & Private**: Zero permissions required. Zero data collected.

## Build & Test Instructions

### 1. Run Unit Tests (Local JVM)
```bash
gradle :app:testDebugUnitTest
```

### 2. Generate Debug APK
```bash
gradle :app:assembleDebug
```
Output location: `app/build/outputs/apk/debug/app-debug.apk`

### 3. Generate Release Android App Bundle (AAB for Google Play)
```bash
gradle :app:bundleRelease
```
Output location: `app/build/outputs/bundle/release/app-release.aab`
